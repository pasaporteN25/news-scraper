# Global News Scraper

Aplicación para scraping de noticias con interfaz gráfica

## Características
- Búsqueda por palabras clave
- Soporte para múltiples fuentes
- Interfaz moderna con CustomTkinter
- Exportación a JSON/CSV

## Configuración
Copiar `config.example.py` a `config.py` y completar con tus API keys
